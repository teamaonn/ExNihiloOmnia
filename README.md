# Ex Nihilo Omnia

The original Forge 1.10.2 source is preserved at the repository root.

The Minecraft **26.3 Fabric port** is under
[`fabric-26.3`](fabric-26.3/README.md). The current alpha includes sieves, heavy
sieves, meshes, compression, hammers, crooks, silkworms and spreading infested
leaves, plus processing barrels with composting, rain collection, fluid crafting
and hopper/pipe access, porcelain crucibles, Witchwater, spores and summoning dolls.
Current checkpoint: **0.5.0-alpha.1**. The full Omnia feature set remains in scope; see the port README for
implemented behavior, requirements, validation and pending systems.
